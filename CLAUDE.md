# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

Alby Go: Expo / React Native lightning wallet that talks to any [NWC](https://nwc.dev) wallet service (e.g. Alby Hub) via `@getalby/sdk`. Package manager is **yarn**.

## Commands

```bash
yarn start                 # expo dev server (yarn start:clean to reset metro cache)
yarn android | yarn ios    # local native build + run (expo run:*)
yarn device:ios            # run on physical device (needed for push notifications)
yarn lint                  # eslint + tsc + prettier --write
yarn lint:js               # eslint only (CI)
yarn format                # prettier --check (CI)
yarn tsc:compile           # typecheck (CI)
yarn test                  # jest (jest-expo preset)
yarn test hooks/__tests__/useHandleLinking.ts   # single test file
yarn test -t "name"        # single test by name
```

CI (`.github/workflows/linting.yml`) runs `lint:js`, `format`, `tsc:compile`. Husky + lint-staged run prettier/eslint/tsc on commit.

`ios/` and `android/` are gitignored, generated by `yarn expo prebuild`. Re-run prebuild after editing `assets/ios/NotificationService.m`, `assets/android/MessagingService.kt`, `app.config.js`, or anything in `plugins/`. Android notifications need `google-services.json` + `.env.local` with `GOOGLE_SERVICES_JSON=./google-services.json`. Notifications don't work in Expo Go (`IS_EXPO_GO` guards skip that code).

Release steps (version bump in both `app.config.js` and `package.json`, tag, EAS build/submit, Zapstore via `zsp`) are in `RELEASE.md`.

## Architecture

**Routing split: `app/` vs `pages/`.** `app/` is expo-router file-based routing; each route file is a thin `.js` wrapper that just renders a component from `pages/` (e.g. `app/(app)/send/index.js` → `pages/send/Send.tsx`). Put screen logic/UI in `pages/*.tsx`; only add/rename files in `app/` to change routes.

**Gatekeeping.** `app/_layout.tsx` loads fonts/theme, inits Sentry, prompts for notifications, and wraps everything in SWR, theme, bottom-sheet, `UserInactivityProvider`, `SessionProvider`. `app/(app)/_layout.tsx` redirects in order: not onboarded → `/onboarding`; no session (biometric lock enabled and not unlocked) → `/unlock`; no wallets → `/settings/wallets/setup`. `UserInactivityProvider` re-locks after `INACTIVITY_THRESHOLD` in background.

**State: single zustand store** (`lib/state/appStore.ts`). Persisted synchronously to `expo-secure-store` via `lib/secureStorage.ts`. Wallets and address book entries are stored as indexed keys (`wallet0`, `wallet1`, …) and loaded by iterating until a gap — removals must re-pack indices. The store also holds the active `NWCClient` for the selected wallet.

**NWC data fetching.** Hooks in `hooks/` (`useBalance`, `useTransactions`, `useInfo`) use SWR with fetchers built by `lib/createNwcFetcher.ts`, which pulls the current `nwcClient` from the store and suppresses errors caused by iOS severing the websocket when the app is backgrounded (via `lastAppStateChangeTime`).

**Payment input pipeline.** Scanned/pasted/deep-linked text funnels through `lib/initiatePaymentFlow.ts` (BIP21 `bitcoin:` → lightning param, `lightning:` prefix, merchant QR → lightning address via `lib/merchants.ts`, LNURL pay/withdraw, BOLT11, lightning address) and routes to the matching `send/*` or `receive/*` screen. Deep links: `hooks/useHandleLinking.ts` → `lib/link.ts` (`SUPPORTED_SCHEMES`, including `nostr+walletconnect:` and NWA `nostr+walletauth:` for wallet connection); deep links are ignored until onboarded + unlocked + a wallet exists.

**Push notifications.** JS side registers per-wallet with Alby's push service (`lib/notifications.ts`, `services/Notifications.ts`). Native decryption happens outside JS: iOS Notification Service Extension (`assets/ios/NotificationService.m`) and Android `MessagingService.kt`, wired by config plugins in `plugins/` and `app.config.js`. Because those can't read secure-store, `lib/notificationsNativeStorage.ts` mirrors wallet name + NWC shared secret into iOS app-group UserDefaults / Android SharedPreferences keyed by wallet pubkey; keep that in sync when adding/removing/renaming wallets.

## Conventions

- Path alias `~/*` → repo root.
- Styling: NativeWind (Tailwind classes via `className`), theme tokens in `global.css` / `tailwind.config.js`. UI primitives in `components/ui/` follow react-native-reusables/shadcn style (`components.json`).
- Errors surfaced to users via `errorToast(error, "context")` from `lib/errorToast.ts`.
- Expo SDK upgrades: use the `expo-upgrade` skill in `.claude/skills/`.
